# Operational knowledge templates

Use these files as default base content for each operational module.

Canonical contract reference:

- `backend/RAG_KNOWLEDGE_INDEX_PLAYBOOK.md`

Recommended order:

1. `facts-canonicos.md`
2. `rules-decision-table.md`
3. `contracts-action-schema.md`
4. `permissions-limits-matrix.md`
5. `feedback-execution-log.md`

How to use:

- Copy each file and replace placeholders with real tenant data.
- Keep version dates in `YYYY-MM-DD` format.
- Avoid free text for rules and contracts when a table or schema is possible.
- Upload the resulting files from the Knowledge module in the web app.
